# 带力控制 VLA 工作的评测与所用 Benchmark 调研（详细版）

更新日期：2026-10-15。本文按“工作 → 评测任务集/benchmark → 评测方式 → 值得收集的部分”组织。

## 1. 调研范围、选文依据与结论

**核心对象：将末端/腕部六维力与力矩用于感知、动作生成或闭环控制，执行器使用夹爪的 VLA 工作。**“使用夹爪”并不要求论文专门控制夹持力。指尖力/触觉 VLA、关节扭矩 VLA、力蒸馏 VLA 作为相关分支单独标记，避免混成腕部六维力方法。

本文收集 **18 项方法工作：8 项核心相关、8 项扩展相关、2 项相邻系统**，另收集 ForceBench 这项直接评估力感知 VLA 的 benchmark 工作。逐项标明对应论文、任务来源、试验次数、指标与协议。本文的“自建任务集”表示论文在自己的机器人和物体上搭建评测；不意味着作者提供了同名、可安装的标准 benchmark。

**主要发现：这些方法大多使用论文自建真机任务集。**共同高频任务是插接、按压、擦拭、工具操作与装配；任务同名不代表物体、初始分布、控制器和成功判据一致。真正值得收集的首先是这些论文自己的实验协议；其中比较突出的有：CR-VLA-Force 的定量恒力擦拭，Tactile-VLA 的力语言迁移，TORL-VLA 的多阶段无损全流程，ForceDelta-VLA 的单/双臂与延迟测试，Tabero 的夹持力过程指标。ForceBench 是新增的统一比较框架，不应倒推为其他早期方法原论文已经使用它。[各项原文见后文对应小节]

本次以论文原文、补充材料、官方项目页与仓库为证据；检索词覆盖 force/wrench/torque/tactile/compliance VLA。论文列表只用于发现线索，不作为实验事实来源。未安装、运行或复现环境。部分论文按指定 v1/v2 阅读，来源版本在链接中保留；缺失信息明确标“未确认”，不根据百分比反推试验量。

## 3. 核心工作：逐篇核查评测方式

### W01 — ForceVLA（2025）

**对应评测：ForceVLA 原论文自建五任务真机套件，训练数据名为 ForceVLA-Data。**不是在某个通用仿真榜单上得分。

- 平台/力：Flexiv Rizon 7-DoF + Dahuan夹爪；TCP外部六维 wrench，原文称估计值；动作是TCP目标位姿与夹爪宽度。
- 任务/试验：按瓶、插头、USB各20次，擦板10次，削黄瓜15次；每次削皮包含15个stroke。数据共244条轨迹。
- 计分：以任务成功率为主；擦板区分完成擦拭动作与彻底擦除；削皮另计平均长度与清理所需stroke。
- 泛化/对照：无力与简单加力的π0/π0-fast；新物体、高度变化、遮挡和不稳定插座。

**值得收集：**五任务配置、擦板的两级成功定义、削皮质量指标、遮挡/不稳定插座测试。局限是没有系统给出外部目标 wrench 的六轴跟踪误差。

来源：[ForceVLA §4.3、§5.1–5.3](https://arxiv.org/html/2505.22159v1)、[项目页](https://sites.google.com/view/forcevla2025/)。

### W02 — ForceVLA2（2026）

**对应评测：ForceVLA2 原论文在 ForceVLA2-Dataset 对应的五个自建真机任务上测试。**

- 平台/力：Flexiv Rizon 4s + DH AG-95夹爪；末端6D F/T，采集300 Hz；框架输出混合力—位置动作。
- 任务：按瓶、清洁花瓶、擦板、取盘、齿轮装配；数据为1,000条轨迹。
- 协议：每任务20次独立试验，主指标为任务成功率。
- 对照：ACP、π0、π0.5、ForceVLA和简单力输入版本；分析力提示、融合模块与跟随/重定位表现。

**值得收集：**清洁花瓶引入变化表面法向，取盘涉及受限空间与接触，齿轮装配涉及约束接触；比只做平面擦拭更丰富。不能将避免过载的现象描述等同于完整的六轴定量力控 benchmark。

来源：[ForceVLA2 §4–5及附录](https://arxiv.org/html/2603.15169v1)、[CVPR正式论文](https://openaccess.thecvf.com/content/CVPR2026/papers/Li_ForceVLA2_Unleashing_Hybrid_Force-Position_Control_with_Force_Awareness_for_Contact-Rich_CVPR_2026_paper.pdf)、[项目](https://sites.google.com/view/force-vla2/home)。

### W03 — FAVLA（2026）

**对应评测：FAVLA 四任务真机套件，无独立正式 benchmark 名称。**

- 平台：Monte双臂平台，X-ARM手臂，末端法兰6轴F/T及相机。
- 任务/次数：USB插入25、齿轮装配30、翻盒20、擦板10。示教分别80/80/50/50条。
- 指标：任务成功率；齿轮装配、翻盒另测每trial峰值接触力，再跨trial平均，结果分别为7.7 N、9.9 N。
- 对照：π0、π0+Force、TA-VLA、ForceVLA；比较力注入、力变化预测及固定/自适应频率。

**值得收集：**“成功率+峰值力+更新频率消融”的配套评测。峰值降低是控制过程证据，但不是目标力跟踪误差，也不是独立的无损判据。

来源：[FAVLA §4.1–4.3及附录A.4](https://arxiv.org/html/2602.23648v1)。

### W04 — DAM-VLA: Decoupled Asynchronous Multimodal（2026）

**对应评测：这篇异步多模态 DAM-VLA 的七任务真机套件。**注意它不是另一篇同名 Dynamic Action Model DAM-VLA。

- 平台/信号：Franka Panda，机器人内部提供F/T，主评测记录100 Hz；夹爪操作。
- 任务：叠围巾、擦板、按按钮、按洗手液、插座插入、扫珠入簸箕、Lego排列；每任务15次。
- 指标：成功率、平均episode时长；附录另测SPARC平滑性与tracking lag。
- 对照：同X-VLA骨干、同数据划分，拆分异步、力、视觉记忆与融合方式。

**值得收集：**通过多组对照辨别力、记忆、异步各自贡献。主表控制器为100 Hz，但DAM-VLA重规划约5.5 Hz；不能将其写成每10 ms重新感知并规划。附录还单独测试200 Hz控制器。

来源：[原文 §4、附录D–F](https://arxiv.org/html/2606.12105v1)、[官方项目](https://intuitive-robots.github.io/DAM-VLA/)。

### W05 — CR-VLA-Force / CC-VLA（2026）

**对应评测：CR-VLA-Force论文的自建四任务、多条件真机评测；正文方法称CC-VLA。**

- 平台：UR5e、UMI-like夹爪、6D F/T；慢VLA与500 Hz柔顺控制器。
- 任务/条件：急停按钮、充电插头、旋转窗、恒力擦白板；按钮/白板降低6 cm测试OOD；另设近插座、腕相机不可见孔位的PI-pro。每条件24–25次。
- 关键指标：成功率；白板以40 N法向力为参考，计算平均相对绝对误差，base/OOD为5.52%/8.78%；75 N触发保护停机。

**值得收集：定量恒力擦板协议。**它明确测“是否跟住目标力”，比只看擦干净更贴近力控。40 N、75 N只是该论文对象和硬件设置，不能当通用阈值；该项主要检验法向力而非完整六维跟踪。

来源：[原文 §4.1–4.2、Table I](https://arxiv.org/html/2609.05832v1)。

### W06 — TAO-Force（2026）

**对应评测：TAO-Force五任务ID/OOD套件与离线反事实力输入实验。**

- 平台：AgiBot G1双臂，腕部六轴F/T；VLA与高速导纳执行链路分层。
- 任务：同外观重量分拣、削黄瓜、按泵头、擦板、切黄瓜；ID/OOD各30次/任务。OOD包括高度、工具、光照变化。
- 指标：任务成功；力/力矩预测MSE；固定视觉、交换空/满罐力信号，统计轨迹误差与路由Flip Rate，使用20条测试轨迹。
- 口径：主比较平均值只包含除重量分拣外的四任务；无力基线在分拣任务标N/A。

**值得收集：反事实力输入测试。**它比仅展示注意力图更直接检查“动作是否依赖力”。但这是离线轨迹响应，不是新一轮真机反事实成功率；预测MSE也不等于执行跟踪误差。

来源：[原文 §V-A–V-D](https://arxiv.org/html/2609.18497v1)。

### W07 — ForceDelta-VLA（2026）

**对应评测：ForceDelta-VLA自建九任务，五单臂+四双臂。**

- 力来源：Franka Panda与X Square平台均用机器人关节扭矩估计末端6D wrench；不是额外腕部F/T传感器。每任务200条示教、20次评测。
- 任务：单臂翻物、USB、开柜、按键、擦板；双臂拔插头、插插头、开抽屉、擦板。
- 指标：成功率；峰值力和时间按**成功trial**汇总；另测参考动作延迟、未见物体与组件消融。
- 对照：ForceVLA、π0.5、TA-VLA、ImplicitRDP和Temporal Teacher；共享任务数据与控制限制。

**值得收集：单/双臂任务套件及延迟鲁棒性协议。**读取峰值力表时必须保留“成功样本”分母；快纠偏只改位姿，夹爪命令来自参考动作，不应归为夹持力闭环控制。

来源：[原文 §III-A、§IV](https://arxiv.org/html/2609.18242v1)。

### W08 — ForceRFT（2026）

**对应评测：ForceRFT自建三任务、限时自主成功协议。**

- 平台：Franka FR3 + Robotiq 2F-85 + OnRobot HEX-E腕F/T。
- 任务/判据：插头完整插入、环套柱完全就位后释放；擦板须去除全部文字、抬起擦子并停止。
- 协议：每设置30次；插入/装配限60 s、擦板180 s；不允许人工介入、trial内重置或保护停机。每任务50条示教，在线变体统一30分钟预算，正式评测固定参数。
- 对照：SmolVLA-SFT、力条件prior、残差模仿、ForceRFT；另消融执行时wrench及增量。

**值得收集：完整自主终止与匹配在线预算。**能防止“人救回来也算成功”或“持续擦不停也算完成”。主要结果是自主成功次数，不应补写论文未报告的完整力跟踪分数。

来源：[原文 §V-A–V-C](https://arxiv.org/html/2609.22840v1)。

## 4. 扩展相关 VLA：夹爪接触、关节力矩与力蒸馏

### W09 — Tactile-VLA（2025）

**对应评测：Tactile-VLA三组自建能力测试。**

1. 力语言迁移：USB学softly/hard；充电器学过运动、没学对应力副词，测试成功率和施加力；另测未见副词。
2. 物理常识抓取：重、轻、易碎三类物体，ID/OOD；每物体10次；成功须单次抓起且无可见变形。
3. 失败后调整：白板训练、黑板测试，比较带推理的调力行为。

**值得收集：第一组的跨任务力语义benchmark，以及第二组的无变形抓取。**“零样本”指力语言迁移，不是充电器整个任务从未训练。它是双指触觉/力路线，不应写成腕部六轴F/T。

来源：[Tactile-VLA §3.1–3.4、Tables 1–4](https://arxiv.org/html/2507.09160v1)。

### W10 — TaF-VLA（2026）

**对应评测：TaF-VLA八类自建真实接触任务。**包含管插入、镊子提重、充电宝拔出、白板擦拭、果冻切片、重部件提起、夹具食物抓取、巧克力抓取。每模型每任务15次，按任务特定二元成功条件计分。对照ACT、DP、FreeTacMan、π0.5及适配器版本。

**值得收集：工具把持与不同力需求的任务覆盖。**它用易碎、抗滑、阻力与持续接触检验触觉—力对齐；主结果仍以完成率为主，不是独立的六维目标力跟踪榜单。详细成功条件见原文附录B。

来源：[TaF-VLA §V及附录B](https://arxiv.org/html/2601.20321v1)。注意TaF-VLA与TA-VLA不同。

### W11 — Tabero / Tabero-VTLA（2026）

**对应评测：Tabero benchmark，复用LIBERO场景/轨迹并迁移到Isaac Lab触觉仿真。**因此应标成“LIBERO衍生的Tabero”，不能把分数直接写成原版LIBERO。

- 输入是两指各3D力的拼接，不是腕部三力三力矩；输出解耦的运动与力目标。
- 在firm/gentle指令下报告成功率，以及AG（接触期平均夹持力）、AA（接触期平均施加力）、MG/MA（对应最高5%样本均值）。本次未确认统一的每任务rollout数，不能擅自填20或50。
- 官方仓库含环境、评测、资产/权重入口和训练仓库链接，README记录传感器绑定与版本差异。

**值得收集：夹持内力和外部作用力分开计分。**MG/MA不是单点最大值，也不是P95分位数。

来源：[Tabero §3.4–3.6及实验](https://arxiv.org/html/2605.27886v1)、[官方代码](https://github.com/NathanWu7/Tabero)。

### W12 — TORL-VLA（2026）

**对应评测：TORL-VLA自建latch-box套件，三子任务+一个完整流程。**

- Piper+Pika夹爪、双Tacta指尖；每指SDK给6D wrench，拼为12D，不能标为单腕6D。
- 杯子：抓取、放进狭窄杯架、释放后稳定；搭扣：翻转并压至锁定；鸡蛋：搬运放置、稳定且无可见损伤。
- 子任务与全任务各30次；全任务须连续完成，无介入、重置、停机、掉落或损伤。另报60分钟成功吞吐量与成功全任务平均时间。
- 正式评测不更新参数；ForceVLA/TA-VLA对照已移植到相同π0.5与双指wrench接口。

**值得收集：接触、锁定、易碎抓取结合的全流程benchmark。**基线名字相同不代表原论文的原始实现条件相同。

来源：[TORL-VLA §4、附录A.1–A.2](https://arxiv.org/html/2606.09337v1)。

### W13 — TA-VLA（2025）

**对应评测：TA-VLA自建十任务真机套件。**五接触任务为按键、充电器插入、USB插入、插座拔出、门把转动；五常规任务为抓放瓶、倒液、堆方块、推到目标、开抽屉。每任务20次。比较扭矩观测、扭矩预测及二者组合，并测试不同模型和机器人。

**值得收集：五接触+五常规的分组方式。**它检验收益是否只在接触任务出现，以及是否损害常规能力；输入为关节effort，不应写成腕部6D wrench。正式仓库明确有observation.effort字段。

来源：[TA-VLA §6、Table 5](https://arxiv.org/html/2509.07962v1)、[官方代码](https://github.com/ZZongzheng0918/TA-VLA)。

### W14 — FD-VLA（2026，核对v2）

**对应评测：FD-VLA自建UR5e三任务套件。**擦白板、压急停按钮、插头入插座；每任务50条示教、30次独立测试。分别要求擦除全部可见标记、按钮充分压下且不回弹、插头完全就位。比较DP3、π0、SmolVLA及真实力输入/蒸馏变体。

**值得收集：传感器输入与力蒸馏的相同任务对照。**训练采集真实力，部署不读真实力，所以归入力知识蒸馏分支，不能和实时力反馈方法不加标记地混排。不要把FD-VLA与ForceDelta-VLA混淆。

来源：[FD-VLA v2 §IV](https://arxiv.org/html/2602.02142v2)。

### W15 — MoSS（2026，原文v1与当前主页分开）

**对应评测：MoSS v1夹爪真机四任务套件。**Unstack Cup、PnP Egg、Board Erase、Plug Insertion；每任务24次；杯子分大/小各12，插头三种各8，擦板组合高度等条件。Franka FR3+Robotiq 2F-85+双AnySkin，另用关节torque。联合多任务数据微调GR00T N1.5与π0，比较触觉、torque及其组合。

**值得收集：多种物理模态在同骨干上的比较协议。**平均值旁的标准差要核对统计单位，不能自动解释成多随机训练seed。当前主页另有双OpenArm+RH56F1手的纸张/重量分拣演示，不能把它们直接并入v1的四任务分数。

来源：[MoSS v1 §4与附录A](https://arxiv.org/html/2604.23272v1)、[当前主页](https://jiminlx.github.io/MoSS/)。

### W16 — CompVLA（当前官方项目资料）

**对应评测：CompVLA自建柔顺性任务套件。**擦白板、Pivot、Cup Dispense，外加常规Pick & Place；平台Franka FR3。项目说明每任务100条示教、10 Hz同步，数据包含F/T，但评测时策略不使用F/T输入。

**值得收集：不同柔顺需求+常规任务对照。**它回答可变柔顺性是否有用，不是测实时六维力融合。主页提供均值±标准差，但本次未确认对应训练重复数和每任务评测次数，保持未确认。

来源：[CompVLA官方项目页](https://compvla.github.io/)。

## 5. 相邻系统：保留关联，不混入核心VLA结论

### W17 — ForceFlow（2026）

**对应评测：ForceFlow自建六真机任务。**盖章、插头、按压、USB插入、擦白板、清洁花瓶；每任务20次。成功率之外，Force Fidelity比较trial的力统计量与专家参考：短接触用峰值，持续接触用接触期均值；另设物理/空间OOD测试。

**值得收集：平面/曲面持续接触和物理/位置泛化分开。**该误差不是逐时刻六维wrench跟踪；其VLM定位后切换接触策略的结构，应与端到端VLA区分。

来源：[ForceFlow §4.1–4.4](https://arxiv.org/html/2605.11048v1)。

### W18 — FAWAM（2026）

**对应评测：FAWAM自建四真机任务。**擦白板、削黄瓜、翻盒、擦花瓶；每方法每任务20次、每次最长60秒。Franka平台，ATI腕传感器120 Hz。对照π0.5、GE-Act、ForceVLA、TA-VLA及无残差版本，报告成功率并分析执行时间、力观测/预测/残差贡献。

**值得收集：力预测与执行时残差纠偏的消融。**它是world action model路线，不能仅因比较对象含VLA就重新归类为标准VLA；也不能默认拥有统一通用benchmark。

来源：[FAWAM §4、附录A](https://arxiv.org/html/2606.08555v1)。

### B01 — ForceBench与上述方法到底是什么关系

**对应工作：ForceBench: Benchmarking Force Integration for Robotic Manipulation，2026-10-14发布。**

它提供8个仿真任务：重量分拣、重心分拣、水阀转动、水阀方向、炉灶转动、炉灶按压、抽屉拉动、螺母旋拧；1,600条示教。同π0.5骨干比较无力及六种力接入设计，每方法每任务200次，共用测试种子；另对ForceVLA、ForceFlow作外部比较，并有五真机任务验证。

这里的六维信号是腕—手关节反力，关节系表达、未重力补偿；动作仍为TCP位姿与夹爪目标。主要配置15 Hz控制、一次执行完50步才再查询；因此不能写成15 Hz重新读取力并规划。

**文献关系：ForceBench将ForceVLA等拿来重新评测，不等于ForceVLA原论文用了ForceBench。**由于发布时间很新，本次尚未确认完整代码/数据/权重发布包；应先收集论文协议，再核验复现资源。

来源：[ForceBench §III、§V及附录](https://arxiv.org/html/2610.19604v1)、[项目主页](https://forcebench-platform.github.io/)。

## 7. 横向归纳：这些工作究竟在测什么

| 评测问题 | 实际对应工作 | 现有测法 |
|---|---|---|
| 接触任务是否做成 | W01–W18大多数工作 | 各自物体/初始条件下的成功次数/成功率 |
| 接触是否过猛 | W03 FAVLA、W07 ForceDelta-VLA | 峰值接触力；W07主要表按成功trial统计 |
| 是否跟住给定力 | W05 CR-VLA-Force | 恒定法向参考力与相对绝对误差 |
| 力语言是否迁移 | W09 Tactile-VLA、W11 Tabero | 改指令测真实力及成功；跨词或跨任务 |
| 夹爪是否既稳又轻柔 | W09、W11、W12 | 无变形/无损抓取，夹持力统计，滑落/破损失败 |
| 模型是否真正用力 | W06 TAO-Force | 固定视觉交换力信号、测轨迹路由改变 |
| 力与未来接触是否可预测 | W06、W13等 | 力/扭矩预测误差或联合监督分析 |
| 高频/异步是否必要 | W03、W04、W07 | 频率、记忆、延迟和纠偏路径消融 |
| 能否自主连贯完成 | W08、W12 | 不介入/不重置/限时/无损的全任务成功 |
| 改善是否损害普通操作 | W13、W16 | 常规Pick & Place等对照 |

**归纳结论：**“六维力作为输入”很常见，“逐轴完整六维力矩目标跟踪”并不常见；使用夹爪也不代表测了夹持内力。论文大多把力的作用体现在任务成功、冲击或泛化，只有部分工作进一步给出明确的力跟踪、夹持力或无损全过程协议。讨论时应保留这个证据边界。

## 8. 关联资源怎样归档，避免跑偏

上一版中对独立benchmark和自拟实验方案的篇幅已删除。以下资源不作为本报告“核心VLA方法原论文用了哪些benchmark”的主答案：

| 资源类型 | 例子 | 本次处理 |
|---|---|---|
| 非VLA力/触觉策略 | ForceMimic、FoAR、ManipForce、RDP、ImplicitRDP | 作为相关方法/基线线索；不冒充VLA |
| 通用触觉benchmark | OpenViTac、UniVTAC | 未核验其被上述方法的原始评测采用，不写入方法→所用benchmark关系 |
| 通用安全/损伤后评测 | SafeVLA-Bench、ManiPhysicsBench | 可另收集，但不说ForceVLA等原论文用过 |
| 装配仿真底座 | Factory、FORGE | 不因任务同为插接/齿轮就推定论文采用 |
| 训练数据集 | RH20T等 | 数据来源不等于测试benchmark |
| 特殊本体与场景 | 全身人形接触、超声等 | 不作为“六维末端力+夹爪”主线扩展 |

这里不否定它们的价值；只保留能从原文证明的使用关系。具体方法、benchmark、数据集、仿真引擎应分别建字段，不混用名称。
