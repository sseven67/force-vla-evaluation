# 带力控制 VLA 扩展调研（简易版）

日期：2026-10-15。本轮新增12项，扩展到触觉、灵巧手、全身接触、超声探头；详细原文和评测口径见[扩展详细版](./带力控制VLA扩展调研_详细版.md)。

## 先看哪些

- **较早代表：FuSe、VTLA**；TLA是无视觉的触觉—语言—动作前序。
- **有公开热度证据：FTP-1、N₀-VTLA**。
- **灵巧手重点：T-Rex、STAR**。
- **全身/移动力控制：FWBC-VLA、Opt2VLA**。
- **专用探头：ForceU-VLA**。

并非所有触觉VLA都会输出目标力。下表标明各自信号和评测，避免将“有触觉”直接当成“有显式力伺服”。

## 工作与所用评测

| 对应工作 | 如何超出“腕部六维力+夹爪” | 所用benchmark/怎么测 |
|---|---|---|
| **FuSe，2025** | DIGIT触觉图像+声音 | 自建桌面/袋中抓取、按钮与组合指令；每scenario 5次；Octo主实验与PaliGemma VLA结果分开 |
| **VTLA，2025** | 双指触觉图像 | 自建孔形/公差插孔；离线动作误差+闭环成功/纠偏步数；真机每设置20次 |
| **FTP-1，2026** | 多类传感器、灵巧手与夹爪 | UniVTAC六任务子集、Sharpa真机与未见传感器迁移；仿真100次/任务、真机20次 |
| **N₀-VTLA，2026** | 规模化触觉基础策略、单/双臂 | NeoReal九任务、UniVTAC八+NeoSim十二任务；SR+阶段进度 |
| **T-Rex，2026** | 双22-DoF手，指端力+形变 | 自建12项灵巧任务，各16次；含多阶段进度评分 |
| **STAR，2026** | 多指与大面积稀疏触觉 | 耳机翻转、叠书取出、明信片、多物体抓取，各20次；SR+子任务完成率 |
| **TacVLA，2026** | 单指压力阵列 | 四类约束拆解+箱内取物，各20次；遮挡、扰动、接触门控消融 |
| **FWBC-VLA，2026** | 轮足机器人身体参与力补偿 | 移动开门、带/不带闭门器、擦板；25次/任务，阶段与最终成功 |
| **Opt2VLA** | Digit双手双脚全身协调、目标接触力 | 搬箱/推箱/擦拭；任务+力意图+实际跟踪联合成功；45次VLA真机测力 |
| **ForceU-VLA，2026** | 超声探头接触人体 | 肝/肾五标准切面，每任务45次；成像成功、步数、力信号 |
| **TLA，2025【前序】** | 只有触觉+语言，不含视觉 | 自建插孔，孔形/间隙变化；闭环每设置50次，最多15次尝试 |
| **OmniVTA，2026【相邻】** | 视觉—触觉世界模型+反射控制 | 六类任务；每物体10次，另测高度、换刀、执行中丢失接触 |

## 最值得收集的几套benchmark

1. **FTP-1对应套件**：跨传感器、跨本体，能测试触觉策略迁移。
2. **T-Rex十二任务**：覆盖翻页、移蛋、挤膏、开锁、抽卡、拧灯泡等多指接触；注意进度评分。
3. **N₀-VTLA的NeoReal/NeoSim**：真实与仿真、单臂与双臂，保留任务成功和阶段rubric两类结果。
4. **Opt2VLA三关联合成功**：不只完成任务，还要力命令符合语言、实际力跟上命令，最贴近“语言驱动的物理交互”评测。
5. **VTLA孔形/公差Sim2Real**：局部纠偏动作质量、任务成功、尝试效率分开统计。
